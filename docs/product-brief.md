# Warwick EventHub

## Problem

Many societies at the University of Warwick have different ways of posting their events. Imagine you are a member of multiple societies, one tells you to look on their instagram, another uses discord, maybe others use the emails? Or maybe a combination? 

EventHub is meant to be used by societies as a one-stop place to advertise their events as they see fit. Societies should be posting their events, and we'll advertise it.

In future iteartions, EventHub could also remind students about saved events before they begin.

## Target Users

Students who are looking for society events all in one place

Societies who want to share their events on one platform and create, edit and delete their own event hassle free.

## Core Use Cases

As a student, I want to search for events by society or
category so that I can discover relevant events and
bookmark the ones I am interested in.

As a student, I want to be able to bookmark/save events that interests me so I can come back to them.

As a student, I want to be able to share events that I think might interest other students so everyone can enjoy the events.

As a student, I want to be able to filter for events to suit my needs, such as no drinking or female-only so that I don't spend time looking at events I know I won't be able to go to.

As a society organiser, I want to publish events alongside pictures so that I can advertise to users about our upcoming events.

As an organiser, I want events to be tied to my account so that I am the only one able to modify them.

As an organiser, I want to see how many people are interested in my events so I can plan ahead.

As an organiser, I want to be able to remove or cancel events so that people aren't turning up to events no longer running.
